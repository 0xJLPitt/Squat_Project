# Squat Analysis Pipeline

這是一個整合了深蹲（Squat）與舉重動作分析的完整專案。本專案將從影片中的 2D 骨架抽取、3D 空間轉換、自動動作切割（Segmentation），到最後的時序資料錯誤偵測（Time-series Classification），整合成一個一條龍的分析管線。

本專案由以下四個核心子專案構成：

## 1. Squat_2dto3d (2D 到 3D 骨架轉換)
此模組負責基礎的 2D 到 3D 骨架座標轉換。
- **作用**：將 2D Pose Estimation（例如 YOLO Pose）所提取的像素級骨架座標，透過相機參數與視角投影技術（Triangulation / Extrinsics）轉換為具有物理意義的 3D 空間座標。
- **目的**：解決 2D 畫面中因拍攝角度產生的遮擋與深度遺失問題，為後續的生物力學分析提供更準確的空間數據。

## 2. Squat_with_AGFormer (基於 MotionAGFormer 的進階 3D 估計)
此模組為 2D 到 3D 轉換的進階深度學習架構實作。
- **作用**：利用 **MotionAGFormer** 框架，透過 Transformer 的注意力機制處理人體骨架的時空特徵。
- **優勢**：相比於傳統轉換，AGFormer 能更好地處理 2D 估計自帶的雜訊，強制施加生物力學的合理性（如骨骼長度一致性與空間連續性），從而提供極度穩定的 3D 關節點序列，非常適合精準的深蹲深度與關節角度計算。

## 3. Squat_Autocutting (動作自動切割與分段)
此模組負責處理連續的骨架時序訊號，將影片自動切割成單次的反覆動作（Repetitions）。
- **作用**：運用訊號處理技術（如關節角度計算、波谷 Trough 偵測、曲率分析等），精準找出動作的「起始點」、「最低點」與「結束點」。
- **目的**：讓後續的 AI 模型不需要處理整段長影片的雜訊，而是專注於一段一段已經被標準化切分出來的深蹲或臥推等獨立動作週期。

## 4. Squat_PatchTST (深蹲錯誤偵測與分類模型)
此模組為本管線的最終分析端，負責判斷動作的正確性。
- **作用**：將原本用於時間序列預測的 **PatchTST** 模型架構進行了修改（替換了預測頭），轉變為一個「多標籤分類模型（Multi-label Classification）」。
- **目的**：讀取已經被轉換為 3D 且自動切割好的動作時間序列，透過基於置信度（Confidence-based）的預測邏輯，來自動檢測深蹲過程中發生的特定錯誤姿勢與動作瑕疵。

---

## 系統工作流程 (Workflow)
1. **輸入**：原始深蹲影片
2. **姿勢估計**：使用 YOLO 等提取 2D 骨架。
3. **3D 投影**：透過 `Squat_2dto3d` 或 `Squat_with_AGFormer` 將其轉換為物理 3D 座標，消除視覺誤差。
4. **自動切割**：資料送入 `Squat_Autocutting`，將連續的動作訊號裁切成單次深蹲的週期。
5. **錯誤分析**：最後將裁切好的標準時序資料送入 `Squat_PatchTST`，輸出對該次深蹲動作的錯誤分類與診斷。
