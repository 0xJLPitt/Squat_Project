# 訓練前準備與專案架構檢查表 (Check Before Train)

這份文件彙整了 `Squat_PatchTST` 專案的核心架構、環境建置步驟以及資料格式範例，在開始訓練模型前，請務必確認以下事項已完成。

---

## 1. 專案核心亮點：魔改版 PatchTST

這包 code 最特別的地方在於它對 **PatchTST**（一種 Transformer 變體）進行了架構上的改造：
原本的 PatchTST 是設計來做時間序列的「未來預測」，但這裡被改編成**「多標籤錯誤分類 (Multi-label Classification)」**。

* **全局視角 (Global Flatten)**：在特徵提取的最後，打破了原模型各關節獨立運算的機制，將所有特徵（時間與空間）一次攤平。這樣模型才能掌握「全身的相對位置」來判斷複雜錯誤（例如：臥推時左右手不平衡）。
* **多標籤預測**：將預測未來的輸出層改為 Classification Head，並搭配 `BCEWithLogitsLoss`。這讓模型可以同時給出多個錯誤動作的「發生機率」（因為一個深蹲或硬舉動作，可能同時發生多種錯誤）。

---

## 2. 專案結構解析

* `PatchTST_train.py`：**主菜**。負責讀取資料、訓練模型、計算 Loss，並會把表現最好的模型權重存下來，同時畫出訓練過程的 Loss/F1 曲線圖。
* `PatchTST_test.py`：**驗證腳本**。載入訓練好的模型進行推論，並產出多標籤的「混淆矩陣 (Confusion Matrix)」與各項指標（F1-score, Accuracy）。
* `models.py`：定義了神經網路模型。裡面除了魔改版的 PatchTST 外，還有提供 ResNet32、LSTM 等作為對照組 (Baseline)。
* `dataset/`：處理 PyTorch 的 DataLoader，負責將 CSV 等格式的資料轉換成 Tensor 餵給模型。
* `tools.py`：工具箱。包含計算各項評估指標、畫圖、以及動態調整學習率的 Scheduler。

## 3. 準備執行步驟 (How to Run)

### 步驟一：建立與啟動 Conda 環境
專案內有附上 `environment.yaml`，請在命令提示字元 (或 PowerShell) 確保您在該專案目錄下，並執行：
```bash
# 1. 建立環境 (會安裝 PyTorch 等必備套件)
conda env create -f environment.yaml

# 2. 啟動環境
conda activate deadlift_env
```

### 步驟二：準備資料 (Data Preparation)
請在 `Squat_PatchTST` 內新增 `data/` 資料夾，並依照專案需求建立子目錄放入對應資料。資料結構必須如下：
```text
Squat_PatchTST/
└── data/
    ├── deadlift/        <-- 放入硬舉的資料
    └── benchpress/      <-- 放入臥推的資料 (csv格式)
```

### 步驟三：開始訓練與測試
資料和環境都就緒後，就可以用指令跑了。它透過 `--sport` 參數來決定要跑哪種運動：

**訓練 (Train):**
```bash
# 訓練硬舉
python PatchTST_train.py --sport deadlift

# 訓練臥推 (可加上 --split_training True 啟用 K-Fold 交叉驗證)
python PatchTST_train.py --sport benchpress --split_training True
```

**測試 (Test):**
```bash
python PatchTST_test.py --sport deadlift
```

## 4. 訓練資料格式範例 (Data Format Example)

資料格式通常會以 JSON 或是在 CSV 的某一欄中存入陣列字串來表示。在程式讀取進 PyTorch 時，它會被轉換為對應的 Tensor。

我們以一個**「臥推 (Benchpress)」**的單次動作 (1 Rep) 為例，假設這個動作總共被標準化（Normalize）為 **100 個時間幀 (Frames)**，且我們追蹤了 **5 個特徵 (Channels)**（例如：槓鈴高度、左手肘角度、右手肘角度、左肩高度、右肩高度）。

一筆完整的資料結構會長得像這樣：

```json
{
  "subject": "User_001",
  "label": [0, 1, 0, 0],
  "features": [
    [0.85, 175.2, 174.8, 0.45, 0.46],
    [0.83, 170.1, 169.5, 0.45, 0.46],
    [0.79, 160.3, 160.0, 0.46, 0.46],
    "... (中間過程省略) ...",
    [0.30, 85.1, 85.5, 0.48, 0.49],
    "... (推起過程省略) ...",
    [0.85, 174.5, 173.8, 0.45, 0.46]
  ]
}
```

### 欄位詳細說明：

#### 1. `subject` (受測者 ID)
* **範例**：`"User_001"` 或數值 `1`
* **用途**：這是用來做「嚴謹的資料切割」。在做機器學習時，同一個受測者的動作習慣是固定的，如果他的資料同時出現在「訓練集」和「測試集」，模型可能會是在「認人」而不是在「認動作」。所以程式碼會用這個 ID 來確保同一個人的資料只會被分在同一邊。

#### 2. `label` (多標籤錯誤答案)
* **範例**：`[0, 1, 0, 0]` (長度取決於您定義了幾種錯誤)
* **用途**：因為是「多標籤分類」，一個動作可能**同時犯下多種錯誤**。
    * 假設四個標籤分別代表：`[手腕過度彎曲, 槓鈴軌跡不平穩, 臀部離開板凳, 左右手不平均]`
    * `[0, 1, 0, 0]` 就代表：這次的動作只有犯了「槓鈴軌跡不平穩」的錯誤，其他都很標準。
    * 如果是標準動作，就會是 `[0, 0, 0, 0]`。

#### 3. `features` (時間 x 特徵維度的 2D 陣列)
* **結構**：這是一個矩陣 (Matrix)。在這個例子中是 `100 (Time) x 5 (Channel)` 的二維陣列。
* **Time (列, Rows)**：由上到下，代表時間的流逝。第一列是動作剛開始（槓鈴最高點），中間列是動作最底部（槓鈴碰到胸口），最後一列是動作結束。
* **Channel (欄, Columns)**：由左至右，代表您擷取的特徵數據。
    * `欄位 0`: 0.85 (槓鈴的 Y 軸高度)
    * `欄位 1`: 175.2 (左手肘的伸展角度，接近 180 度代表打直)
    * `欄位 2`: 174.8 (右手肘的伸展角度)
    * `欄位 3`: 0.45 (左肩的 Y 軸高度)
    * `欄位 4`: 0.46 (右肩的 Y 軸高度)

當這筆資料送進 **PatchTST 模型** 時，模型會利用這個 2D 陣列去觀察在整個時間區段內，各個關節角度與高度的變化模式，並輸出最終預測的錯誤機率！

## 5. 常見問題 (Q&A)

### Q1: 資料給入後，會自動切分 Train / Val / Test 嗎？
**會的！**
當所有資料透過 CSV 送進模型後，程式會自動以 **7 : 1 : 2** 的比例（70% 訓練、10% 驗證、20% 測試）切分資料。
執行訓練腳本時，強烈建議加上 `--subject_split True` 參數，程式會以「受測者 ID (subject)」為單位來切分（例如把 70% 的人的資料全放訓練集）。這樣可以確保模型是真的學會看「動作錯誤」，而不是在「死背」某個人的體態。

### Q2: 錯誤類別標籤 (Label) 只要給 0 或 1 嗎？需要解釋錯誤是什麼嗎？
**只要給 0 或 1，不需要解釋！**
神經網路看不懂文字，對它來說錯誤就只是「類別 0」到「類別 N」。
例如深蹲有 5 種錯誤，您的標籤只需要固定順序寫成 `[0, 0, 0, 1, 1]` 即可。模型訓練結束後，推論的結果也會是一個長度為 5 的陣列（各類別的發生機率），您自行對應機率與真實錯誤種類即可。
目前程式碼已擴充支援 `squat`，並將深蹲的錯誤種類 (`num_classes`) 預設為 5。

## 6. 特徵工程與 SHAP 分析流程 (Feature Engineering & SHAP Workflow)

在深度學習與可解釋性 AI (Explainable AI) 的標準工作流程中，**必須先完成特徵處理 ➡️ 訓練 PatchTST 模型 ➡️ 最後才跑 SHAP 分析**。
這是一個透過「特徵選擇 (Feature Selection)」不斷迭代優化模型的黃金循環。

### Step 1: 特徵工程 (資料預處理)
在把資料餵給神經網路之前，需先在原始座標資料上，計算出所需的物理與統計特徵：
1. **Z-score**: 將座標或特徵做標準化，消除不同受測者身高的尺度差異。
2. **Velocity (速度)**: 座標對時間的一階微分，捕捉動作的快慢。
3. **Acceleration (加速度)**: 座標對時間的二階微分，捕捉爆發力或動作的不穩定性。
4. **Ratio of Variation (變異率)**: 衡量某個關節或角度在一段時間內的波動程度。
將這些計算完的數值串接成最終的 `features` 矩陣，存成 CSV 檔（如深蹲有 5 個座標加上這 4 種處理，可能會擴充成 25 個 Channels）。

### Step 2: 訓練第一版模型 (Train Model V1)
使用包含所有特徵的 CSV，訓練出第一版 PatchTST (V1)。
目標是建立 Baseline，讓模型在擁有所有可能資訊的情況下，盡可能達到最高的 F1-score 和 Accuracy。

### Step 3: SHAP 分析與關鍵特徵洞察 (SHAP Analysis)
確認模型表現良好後，將「訓練好的模型」與「測試集資料」送進 SHAP 分析。
SHAP 會告訴您模型判斷錯誤時，是依賴哪些特徵做出的決定（例如：其實判斷深蹲錯誤，『加速度』貢獻了 70%，但『Z-score』幾乎無關，或是手部關節特徵完全是雜訊）。

### Step 4: 迭代優化 (Train Model V2)
根據 SHAP 的結果進行特徵選擇，**拔除沒有貢獻或造成雜訊干擾的特徵**，保留關鍵特徵。
使用這份去蕪存菁的資料，重新訓練 **PatchTST (V2)**。
通常 V2 模型會比 V1 帶來三大提升：
* **準確率更高**（移除了干擾判斷的雜訊）。
* **泛化能力更強**（專注在真正重要的物理機制上）。
* **模型更輕量、跑得更快**（輸入的 Channel 數減少）。
